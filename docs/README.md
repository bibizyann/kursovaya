# Документация проекта

Здесь хранятся модель производственного участка, архитектурные решения и инструкции по работе со стендом. Документы отделяют согласованное поведение системы от уже реализованных возможностей.

## Производственный участок

- [Модель мелкосерийного сборочного цеха](architecture/assembly-workshop.md): производственный маршрут, шесть рабочих мест, восемь устройств, переналадка и границы симуляции.

- [Контракт телеметрии](architecture/telemetry.md): граница реализации, снимки, единицы, счётчики и правила приёма.

## Архитектурные решения

- [ADR 0001: топология исполнения](adr/0001-runtime-topology.md).
- [ADR 0002: желаемое состояние и владение ресурсами](adr/0002-resource-ownership.md).
- [ADR 0003: каналы взаимодействия](adr/0003-communication-channels.md).
- [ADR 0004: модель сборочного цеха](adr/0004-assembly-workshop-model.md).
- [ADR 0005: реализация моделей оборудования](adr/0005-equipment-simulation.md).
- [ADR 0006: граница симулируемой телеметрии](adr/0006-simulated-telemetry.md).

Существенные архитектурные решения фиксируются отдельными ADR. Описания предметной области находятся в `architecture/`, воспроизводимые эксплуатационные инструкции — в `runbooks/`. При изменении принятого решения новый ADR должен явно указывать, какое предыдущее решение он заменяет.
